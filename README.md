# TollMate 🚗

### Smarter Toll Travel

TollMate is a simple and user-friendly web application designed to make toll-road travel easier. It provides useful tools for checking toll-related information, estimating travel distance, exploring toll plazas, and accessing helpful travel information.

## Features

- **Toll Balance** – Check and manage toll balance information.
- **Distance Calculator** – Calculate the distance between locations for better trip planning.
- **Toll Plazas** – Explore available toll plazas and their information.
- **Help & Guidance** – Access useful information and assistance related to toll travel.
- **Responsive Interface** – Designed to provide a smooth experience across different screen sizes.
- **Simple Navigation** – Easy-to-use interface for accessing different TollMate features.

## Tech Stack

- **HTML5** – Structure and content
- **CSS3** – Styling and responsive design
- **JavaScript** – Interactive functionality
- **Git & GitHub** – Version control and project hosting

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/manidharreddy0909/Tollmate.git
```

### 2. Navigate to the Project

```bash
cd Tollmate
```

### 3. Run the Project

Since TollMate is a frontend web application, no backend installation is required.

You can simply open:

```text
index.html
```

in your browser.

For the best development experience, you can also use **VS Code Live Server**.

## How It Works

1. Open the TollMate homepage.
2. Choose the required service.
3. Enter the necessary travel or toll information.
4. Use the available tools to get the required information.
5. Navigate between different sections using the application menu.
